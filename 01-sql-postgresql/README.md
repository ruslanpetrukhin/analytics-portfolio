# SQL и PostgreSQL

Аналитический проект на PostgreSQL: исследование заказов интернет-магазина, выручки, товарной структуры и клиентской базы.

## Цель проекта

Получить практический опыт решения бизнес-задач с помощью SQL: от объединения таблиц и построения представлений до расчёта KPI и интерпретации результатов.

## Структура данных

В проекте используются таблицы:

- `customers` — клиенты;
- `products` — товары;
- `all_orders` — заказы;
- `order_items` — состав заказов;
- `order_status` и `order_status_history` — статусы заказов и история их изменения.

## Аналитические задачи

- Анализ выручки и количества заказов.
- Расчёт месячной динамики выручки и среднего чека.
- Рейтинг товаров по выручке.
- Анализ концентрации выручки по товарам и клиентам.
- Определение доли повторных покупателей.
- Создание представлений для повторного использования бизнес-логики.
- Проверка корректности расчётов и согласованности метрик.

## Инструменты

- PostgreSQL
- SQL: JOIN, CTE, агрегатные функции, оконные функции, представления.
- Python и Power BI используются в отдельных проектах портфолио.

## Бизнес-правило расчёта выручки

Учитываются заказы со статусами `paid`, `processing`, `shipped` и `delivered`.

Заказы со статусами `new` и `cancelled` исключаются.

Выручка рассчитывается на основании стоимости товарных позиций в заказе.

### Бизнес-интерпретация

- Наибольшая месячная выручка наблюдалась в сентябре 2026 года — около 6,99 млн ₽.
- Топ-10 товаров формируют 57,26% общей выручки. Это указывает на концентрацию продаж по товарному ассортименту.
- На топ-5 клиентов приходится 36,27% выручки.
- Повторные покупки совершили 7 из 27 клиентов с выручкой. Это доля повторных покупателей за весь рассматриваемый период, а не когортный retention.

Концентрация выручки по отдельным товарам и клиентам может быть основанием для дальнейшего анализа маржинальности, запасов и клиентской активности.

## Основные SQL-компетенции

- Группировка и агрегация данных.
- Использование CTE и оконных функций.
- Расчёт бизнес-метрик.
- Создание SQL-представлений.
- Анализ клиентской и товарной структуры выручки.
