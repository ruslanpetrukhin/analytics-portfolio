# SQL и PostgreSQL

Раздел портфолио, посвящённый работе с реляционными данными и решению аналитических задач с помощью SQL.

## Что входит в раздел

- Анализ выручки и заказов интернет-магазина.
- Агрегация данных по месяцам.
- Рейтинг товаров по выручке.
- Анализ клиентской базы и повторных покупок.
- Создание представлений для повторного использования бизнес-логики.
- Проверка корректности расчётов и согласованности метрик.

## Инструменты

- PostgreSQL
- SQL: JOIN, CTE, агрегатные и оконные функции, представления

## Бизнес-правило расчёта выручки

Учитываются заказы со статусами `paid`, `processing`, `shipped` и `delivered`. Заказы со статусами `new` и `cancelled` исключаются.

*Примечание: данные учебные; результаты не являются показателями реального бизнеса.*

## Результаты

SQL-запросы, результаты анализа и описание бизнес-выводов будут добавлены по мере оформления проекта.
