# SQL и PostgreSQL

Аналитический проект на PostgreSQL: исследование заказов интернет-магазина, выручки, товарной структуры и клиентской базы.

## Цель проекта

Решение аналитических и бизнес-задач с помощью SQL: объединение данных из нескольких таблиц, расчёт KPI, анализ продаж и клиентского поведения, создание представлений для повторного использования бизнес-логики.

## Структура данных

В проекте используются таблицы:

- `customers` — клиенты;
- `products` — товары;
- `all_orders` — заказы;
- `order_items` — состав заказов;
- `order_status` и `order_status_history` — справочник статусов и история их изменения.

## Аналитические задачи

- Анализ выручки и количества заказов.
- Расчёт месячной динамики выручки и среднего чека.
- Ранжирование товаров по выручке.
- Анализ концентрации выручки по товарам и клиентам.
- Определение доли повторных покупателей.
- Анализ последовательности заказов клиентов.
- Сегментация заказов по времени относительно первой покупки клиента.
- Создание представлений для повторного использования бизнес-логики.
- Проверка корректности расчётов и согласованности метрик.

## Инструменты и SQL-компетенции

- **СУБД:** PostgreSQL.
- **Объединение данных:** JOIN.
- **Подготовка запросов:** CTE, подзапросы.
- **Агрегация:** GROUP BY, HAVING, агрегатные функции.
- **Аналитические расчёты:** оконные функции, ранжирование, накопительные показатели.
- **Повторное использование логики:** VIEW.
- **Оптимизация:** базовый анализ выполнения запросов через EXPLAIN.

## Бизнес-правило расчёта выручки

В расчёт выручки включаются заказы со статусами `paid`, `processing`, `shipped` и `delivered`.

Заказы со статусами `new` и `cancelled` исключаются.

Выручка рассчитывается на основании стоимости товарных позиций:

`revenue = quantity * unit_price`

Для расчёта используется цена товара, зафиксированная непосредственно в заказе, а не текущая цена из справочника товаров.

### Бизнес-интерпретация

- Максимальная месячная выручка за рассматриваемый период наблюдалась в сентябре 2026 года — около 6,99 млн ₽.
- Топ-10 товаров формируют 57,26% общей выручки, что указывает на концентрацию продаж по товарному ассортименту.
- На топ-5 клиентов приходится 36,27% выручки.
- Повторные покупки совершили 7 из 27 клиентов с выручкой — 25,93%.

Доля повторных покупателей рассчитана за весь рассматриваемый период. Это не когортный retention и не показатель удержания клиентов.

Полученные результаты могут стать основой для дальнейшего анализа маржинальности товаров, управления запасами и клиентской активности.

## Ограничения

- Используется учебная база данных, а не реальные коммерческие данные.
- Для анализа прибыли необходимы данные о себестоимости товаров.
- Доля повторных покупателей за период не заменяет полноценный когортный анализ удержания.
