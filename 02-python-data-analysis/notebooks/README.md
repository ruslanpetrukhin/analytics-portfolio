# Python Data Analysis

Проект по исследовательскому анализу данных интернет-магазина с использованием Python и библиотек анализа данных.

## Цель проекта

Провести полный цикл анализа данных: изучить исходный датасет, проверить качество данных, подготовить данные для анализа, исследовать продажи и клиентское поведение, сформулировать бизнес-выводы.

## Данные

Исходный датасет содержит 5 003 строки и 10 столбцов:

- `order_id` — идентификатор заказа;
- `customer_id` — идентификатор клиента;
- `order_date` — дата заказа;
- `product` — товар;
- `category` — категория товара;
- `quantity` — количество;
- `price` — цена;
- `discount` — скидка;
- `status` — статус заказа;
- `revenue` — исходная выручка.

Данные учебные и используются исключительно для демонстрации аналитических навыков.

## Этапы анализа

### 1. EDA и проверка качества данных
- Изучение структуры и типов данных.
- Анализ пропусков и дубликатов.
- Проверка корректности значений.
- Нормализация статусов заказов.
- Подготовка данных к дальнейшему анализу.

### 2. Очистка и подготовка данных
- Обработка пропущенных значений без случайного заполнения.
- Проверка корректности цен, количества и скидок.
- Фильтрация данных для анализа завершённых продаж.
- Расчёт выручки на основе количества, цены и скидки.
- Сопоставление исходной и расчётной выручки.

### 3. Анализ продаж
- Динамика выручки по месяцам.
- Анализ продаж по категориям.
- Изучение структуры выручки.
- Расчёт скользящего среднего.

### 4. ABC-анализ
Классификация товаров по их вкладу в общую выручку:
- A — товары, формирующие основную долю выручки;
- B — товары со средним вкладом;
- C — товары с наименьшим вкладом.

### 5. XYZ-анализ
Оценка стабильности спроса на товары с использованием коэффициента вариации. Для расчёта учитываются полные месячные периоды, включая месяцы без продаж.

### 6. Когортный анализ
- Формирование когорт по месяцу первой покупки.
- Расчёт возвращаемости клиентов.
- Построение таблицы когортного удержания.

## Бизнес-задачи

Анализ позволяет исследовать:
- динамику и структуру продаж;
- вклад отдельных товаров и категорий в выручку;
- стабильность спроса;
- поведение клиентов после первой покупки;
- качество исходных данных и согласованность показателей.

## Ограничения

Датасет учебный. Результаты не являются показателями реального бизнеса.

При интерпретации необходимо учитывать качество исходных данных, правила фильтрации и ограничения доступных признаков. В частности, выручка не равна прибыли: в датасете нет данных о себестоимости и операционных расходах.
