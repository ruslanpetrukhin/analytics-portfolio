# Notebooks

Материалы проекта Python Data Analysis.

## Содержимое

- `final_python_portfolio.ipynb` — Jupyter Notebook с полным циклом анализа данных: очистка, EDA, анализ продаж, ABC/XYZ-анализ и когортный анализ.
- `techmarket_python_case.xlsx` — исходный учебный датасет, используемый в ноутбуке.
- `data/` — папка с дополнительной информацией об исходных данных.
