# Python Data Analysis

Исследовательский анализ данных интернет-магазина TechMarket с использованием Python. Проект охватывает полный цикл аналитической работы: от проверки качества исходных данных до анализа продаж, товарного ассортимента и повторных покупок клиентов.

## Цель проекта

Исследовать продажи и клиентское поведение, оценить структуру выручки, выявить особенности товарного спроса и проверить качество исходных данных.

## Данные

Исходный датасет содержит 5 003 строки и 10 столбцов:

- `order_id` — идентификатор заказа;
- `customer_id` — идентификатор клиента;
- `order_date` — дата заказа;
- `product` — товар;
- `category` — категория товара;
- `quantity` — количество;
- `price` — цена;
- `discount` — скидка;
- `status` — статус заказа;
- `revenue` — исходная выручка.

Данные учебные и используются исключительно для демонстрации аналитических навыков.

## Этапы анализа

### 1. EDA и проверка качества данных

- Изучение структуры и типов данных.
- Анализ пропусков и дубликатов.
- Проверка корректности дат, цен, количества и скидок.
- Анализ распределения статусов заказов.
- Проверка согласованности исходной и расчётной выручки.

### 2. Очистка и подготовка данных

- Удаление полных дубликатов.
- Нормализация статусов заказов.
- Обработка пропусков без создания искусственных значений.
- Формирование аналитической выборки из заказов со статусом `completed`.
- Исключение некорректных записей из денежного анализа.
- Пересчёт выручки по формуле:

`revenue = quantity × price × (1 − discount)`

- Сравнение исходной и расчётной выручки.

### 3. Анализ продаж

- Динамика выручки и количества заказов по месяцам.
- Расчёт среднего чека.
- Анализ продаж по категориям.
- Расчёт изменения месячной выручки.
- Визуализация результатов.

### 4. ABC-анализ

Классификация товаров по накопительной доле выручки:

- A — до достижения 80% общей выручки;
- B — следующие товары до достижения 95%;
- C — оставшиеся товары.

При пересечении порога товар включается в соответствующую категорию.

### 5. XYZ-анализ

Оценка стабильности спроса на товары через коэффициент вариации (CV):

- X — CV до 10%;
- Y — CV от 10% до 25%;
- Z — CV выше 25%.

Для каждого товара формируется полный календарь месяцев наблюдения. Месяцы без продаж учитываются как нулевые продажи.

### 6. Когортный анализ

- Формирование когорт по месяцу первой завершённой покупки.
- Расчёт количества клиентов в каждой когорте.
- Расчёт месячного retention.
- Построение таблицы когортного удержания и heatmap.

Будущие периоды, по которым ещё нет наблюдений, не интерпретируются как нулевое удержание.

### Контроль качества данных

В процессе проверки выявлены:

- 3 полных дубликата;
- 4 пропуска `customer_id`;
- 3 пропуска цены;
- 2 записи с нулевым количеством;
- 2 расхождения между исходной и пересчитанной выручкой более чем на 0,01.

Значение скидки `0.8` сохранено без автоматического исправления: без подтверждения нельзя считать его ошибкой вместо скидки 8%.

## Бизнес-интерпретация

- Категории Smartphones и Audio формируют значительную долю выручки.
- 8 товаров категории A обеспечивают около 81,27% выручки, что указывает на концентрацию продаж в ассортименте.
- XYZ-анализ позволяет разделить товары по стабильности спроса и использовать результат для дальнейшего анализа управления запасами.
- Когортный анализ показывает изменение доли клиентов, возвращающихся к покупкам после первой завершённой покупки.

Полученные результаты могут использоваться как основа для дальнейшего исследования товарного ассортимента, клиентской активности и эффективности продаж.

## Ограничения

- Датасет учебный и не отражает показатели реального бизнеса.
- Выручка не равна прибыли: отсутствуют данные о себестоимости и операционных расходах.
- Неизвестная денежная единица не позволяет обоснованно интерпретировать абсолютные суммы.
- Отсутствие `customer_id` ограничивает клиентский и когортный анализ для части записей.
- Результаты ABC/XYZ зависят от выбранных порогов классификации.
