# Python + PostgreSQL

Проект по анализу данных интернет-магазина: получение данных из PostgreSQL, обработка и исследование с помощью Python и pandas.

## Цель проекта

Продемонстрировать полный аналитический цикл работы с реляционной базой данных: подключение из Python, извлечение и объединение данных SQL-запросами, расчёт бизнес-метрик и проверка согласованности результатов.

## Этапы работы

### 1. Подключение к PostgreSQL
- Подключение к базе данных с использованием SQLAlchemy.
- Получение данных из PostgreSQL в Python.
- Проверка доступности соединения.

### 2. Извлечение и объединение данных
- Выполнение SQL-запросов из Python.
- Объединение таблиц с помощью JOIN.
- Получение данных о заказах, клиентах и товарах.
- Подготовка единого набора данных для анализа.

### 3. Анализ данных с помощью pandas
- Обработка полученных данных.
- Агрегация показателей.
- Анализ выручки по заказам и месяцам.
- Анализ продаж товаров.
- Анализ клиентской выручки.

### 4. Проверка результатов
- Сопоставление результатов SQL-запросов и расчётов pandas.
- Проверка согласованности агрегированных показателей.
- Контроль корректности расчётов выручки.

## Инструменты

- Python

- PostgreSQL
- SQL

## Практические навыки

- Подключение Python к реляционной базе данных.
- Извлечение и объединение данных с помощью SQL.
- Работа с данными из нескольких связанных таблиц.
- Расчёт бизнес-метрик средствами SQL и pandas.
- Сверка результатов разных способов расчёта.
