# Python + PostgreSQL

Проект по извлечению и анализу данных интернет-магазина из PostgreSQL с использованием Python и pandas.

## Цель проекта

Продемонстрировать практическую работу с реляционной базой данных через Python: подключение к PostgreSQL, выполнение SQL-запросов, обработку данных в pandas и проверку согласованности результатов расчётов.

## Что реализовано

### 1. Подключение к PostgreSQL
- Подключение к базе данных через SQLAlchemy.
- Формирование параметров подключения с помощью `URL.create`.
- Безопасный ввод пароля через `getpass`.
- Проверка доступности соединения.

### 2. Извлечение данных
- Просмотр структуры базы и списка таблиц.
- Выполнение SQL-запросов из Python.
- Объединение таблиц заказов, клиентов, моделей и брендов с помощью `JOIN`.
- Использование параметризованных запросов.
- Загрузка результатов в pandas DataFrame.

### 3. Анализ данных в pandas
- Фильтрация заказов по дате.
- Группировка и агрегация данных с помощью `groupby`.
- Анализ количества заказов и проданных единиц.
- Расчёт долей брендов в общем количестве проданных единиц.
- Анализ распределения текущих статусов заказов.
- Обработка дат и расчёт длительности статусных интервалов.

### 4. Сверка результатов SQL и pandas
- Выполнение аналогичной агрегации средствами SQL и pandas.
- Сравнение результатов по количеству проданных единиц и заказов в разрезе брендов.

## Практические компетенции

- Подключение Python к реляционной базе данных.
- Работа с SQLAlchemy и параметрами подключения.
- Извлечение данных из нескольких связанных таблиц.

- Группировка и агрегация данных.
- Сравнение результатов расчётов разными инструментами.

## Ограничения

Проект выполнен на учебной базе данных с небольшим объёмом записей.

В исходной схеме отсутствуют данные о ценах и затратах, поэтому расчёт выручки и прибыли в рамках проекта не выполняется.

История статусов содержит ограниченное количество завершённых интервалов, поэтому результаты расчёта длительности статусов не позволяют делать обобщённые выводы о скорости обработки заказов.

Подключение демонстрирует работу с локальной PostgreSQL-базой. Производственная инфраструктура и автоматизированный ETL/ELT-процесс не реализованы.
