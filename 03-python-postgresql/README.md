# Python + PostgreSQL

Проект по анализу данных интернет-магазина: извлечение данных из PostgreSQL, обработка и исследование с помощью Python и pandas.

## Цель проекта

Продемонстрировать практическую работу с реляционной базой данных через Python: подключение к PostgreSQL, выполнение SQL-запросов, получение данных в pandas, расчёт бизнес-метрик и проверка согласованности результатов.

## Этапы работы

### 1. Подключение к PostgreSQL

- Подключение к базе данных через SQLAlchemy.
- Формирование параметров подключения.
- Безопасный ввод пароля через `getpass`, без хранения его непосредственно в коде.
- Проверка доступности соединения.

### 2. Извлечение данных

- Выполнение SQL-запросов из Python.
- Объединение связанных таблиц с помощью `JOIN`.
- Извлечение данных о заказах, клиентах и товарах.
- Загрузка результатов запросов в pandas DataFrame.

### 3. Анализ данных в pandas

- Проверка структуры и типов данных.
- Обработка полученных наборов данных.
- Агрегация показателей.
- Анализ выручки по заказам и месяцам.
- Анализ товарной и клиентской структуры выручки.

### 4. Сверка результатов

- Сравнение агрегированных результатов SQL и pandas.
- Проверка согласованности расчётов выручки.
- Контроль корректности объединения таблиц и агрегаций.

## Практические компетенции

- Подключение Python к реляционной базе данных.
- Работа с SQLAlchemy и параметрами подключения.
- Извлечение данных из нескольких связанных таблиц.
- Совместное использование SQL и pandas.
- Расчёт бизнес-метрик разными инструментами.
- Проверка согласованности аналитических результатов.

## Отличие от SQL-проекта

В SQL-проекте основной акцент сделан на аналитических запросах непосредственно в PostgreSQL.

В этом проекте акцент смещён на интеграцию SQL и Python: получение данных из базы, дальнейшую обработку в pandas и независимую проверку результатов расчётов.

## Ограничения

Проект выполнен на учебной базе данных. Результаты не являются показателями реального бизнеса.

Подключение демонстрирует работу с локальной PostgreSQL-базой. Производственная инфраструктура и автоматизированный ETL/ELT-процесс в рамках проекта не реализованы.
