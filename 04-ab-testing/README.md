# A/B Testing — калькулятор оценки эксперимента

## Цель проекта

Разработать Excel-калькулятор для сравнения контрольной группы A и тестовой группы B.

Калькулятор позволяет оценить результаты эксперимента с трёх сторон:

- Статистическая значимость изменения конверсии.
- Экономическая эффективность тестируемого изменения.
- Изменение защитных метрик: возвратов и отмен.

## Что реализовано

### 1. Анализ конверсии
- Расчёт Conversion Rate (CR).
- Расчёт абсолютного изменения конверсии в процентных пунктах.
- Расчёт относительного изменения конверсии.
- Двусторонний z-тест для сравнения двух долей.
- Расчёт p-value при уровне значимости α = 0,05.
- Приближённый 95% доверительный интервал разницы конверсий.

### 2. Экономическая оценка
- Расчёт выручки на пользователя.
- Расчёт среднего чека.
- Расчёт прибыли как разницы между выручкой и переменными затратами.
- Расчёт прибыли на пользователя.

### 3. Защитные метрики
- Расчёт количества возвратов и отмен.
- Расчёт доли возвратов и отмен относительно количества заказов.
- Сравнение защитных метрик между группами.

### 4. Итоговая оценка
Формирование рекомендации с учётом статистической значимости, изменения конверсии и прибыли на пользователя.

## Пример расчёта

В демонстрационном заполнении калькулятора:

| Метрика | Группа A | Группа B |
|---|---:|---:|
| Пользователи | 10 000 | 10 000 |
| Конверсии | 500 | 600 |
| CR | 5,0% | 6,0% |
| Выручка | 900 000 | 1 090 000 |
| Переменные затраты | 600 000 | 700 000 |
| Прибыль до прочих расходов | 300 000 | 390 000 |
| Прибыль на пользователя | 30 | 39 |
| Заказы | 520 | 600 |
| Возвраты и отмены | 25 | 25 |
| Доля возвратов и отмен | 4,81% | 4,17% |

### Статистические результаты

- Абсолютное изменение CR: +1 п. п.
- Относительный рост CR: +20%.
- Двусторонний p-value: около 0,001925.
- Приближённый 95% доверительный интервал разницы CR: от +0,37 до +1,63 п. п.

При заданном уровне значимости α = 0,05 изменение конверсии статистически значимо.

## Логика принятия решения

Рост конверсии сам по себе не является достаточным основанием для внедрения изменения.

При оценке результата учитываются:

1. Статистическая значимость изменения CR.
2. Абсолютный и относительный прирост конверсии.
3. Изменение общей прибыли.
4. Изменение прибыли на пользователя.
5. Динамика доли возвратов и отмен.

Статистически значимый рост конверсии не гарантирует экономической эффективности. Итоговое решение должно учитывать финансовый результат и возможное ухудшение защитных метрик.

## Ограничения

- Используется приближённый двусторонний z-тест для сравнения двух долей.
- Предполагаются независимые группы пользователей, корректная рандомизация и одинаковые условия измерения.
- Сравнение «до и после» во времени может быть искажено сезонностью, рекламными кампаниями и другими внешними факторами.
- Прибыль рассчитывается как выручка минус переменные затраты. Это не чистая прибыль и не полноценная маржинальная прибыль с учётом всех расходов.
- Денежный эффект возвратов и отмен отдельно не рассчитывается: доступны только их количество и доля.
- Допустимый порог ухудшения защитных метрик должен быть определён до начала эксперимента.
- Предварительный расчёт размера выборки, MDE и длительности эксперимента не входит в функциональность калькулятора.
