# Power BI — E-commerce Dashboard

## Описание проекта

Интерактивный дашборд интернет-магазина на основе данных PostgreSQL. Проект демонстрирует построение модели данных, разработку DAX-мер и визуальный анализ ключевых бизнес-показателей.

## Что реализовано

- Подключение Power BI к PostgreSQL.
- Построение модели данных и настройка связей между таблицами.
- Создание календарной таблицы.
- Расчёт выручки, количества заказов и среднего чека.
- Исключение отменённых заказов из расчёта выручки.
- Анализ выручки по месяцам и расчёт динамики MoM.
- Анализ вклада товаров в общую выручку и Top 10 товаров.

## Инструменты

- Power BI
- DAX
- Power Query
- PostgreSQL
