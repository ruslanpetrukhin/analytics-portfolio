# Power BI — PostgreSQL Data Analysis

## Описание проекта

Аналитический проект в Power BI на основе данных интернет-магазина из PostgreSQL.

Цель — построить модель данных, разработать DAX-меры и создать отчёт для анализа выручки, заказов и товарной структуры продаж.

## Что реализовано

### 1. Подключение и подготовка данных
- Подключение Power BI к PostgreSQL.
- Импорт необходимых таблиц.
- Настройка типов данных и связей между таблицами.
- Построение модели данных для аналитического отчёта.

### 2. DAX и расчёт показателей
- Создание календарной таблицы.
- Расчёт выручки с помощью `SUMX`.
- Расчёт количества заказов и среднего чека.
- Исключение отменённых заказов из расчёта выручки.
- Расчёт доли товаров в общей выручке с использованием `REMOVEFILTERS`.

### 3. Анализ и визуализация
- Анализ выручки по месяцам.
- Расчёт выручки за предыдущий месяц.
- Расчёт динамики Month-over-Month (MoM).
- Определение Top 10 товаров по выручке.
- Анализ товарной структуры продаж.

## Инструменты

- Power BI
- DAX
- Power Query
- PostgreSQL

## Файл проекта

`power-bi-postgresql.pbix` — файл Power BI с моделью данных, DAX-мерами и визуализациями.

## Практические компетенции

- Подключение BI-инструмента к реляционной базе данных.
- Построение модели данных и настройка связей.
- Разработка вычисляемых показателей на DAX.
- Использование контекстов фильтрации.
- Анализ временной динамики показателей.
- Построение аналитических визуализаций.

## Ограничения

Проект выполнен на учебных данных и локальной базе PostgreSQL. Результаты не являются показателями реального бизнеса.

Для открытия проекта в другой среде потребуется настроить собственное подключение к базе данных.
