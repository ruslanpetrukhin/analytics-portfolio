# Power BI — PostgreSQL Data Analysis

## Описание проекта

Аналитический проект в Power BI на основе данных интернет-магазина из PostgreSQL. Цель — подключить базу данных, построить модель данных, разработать DAX-меры и визуализировать ключевые бизнес-показатели.

## Что реализовано

- Подключение Power BI к PostgreSQL.
- Импорт таблиц и настройка связей между ними.
- Создание календарной таблицы.
- Расчёт выручки, количества заказов и среднего чека.
- Исключение отменённых заказов из расчёта выручки.
- Анализ выручки по месяцам и расчёт динамики MoM.
- Анализ вклада товаров в общую выручку и Top 10 товаров.

## Инструменты

- Power BI
- DAX
- Power Query
- PostgreSQL

## Файл проекта

`power-bi-postgresql.pbix` — файл Power BI с моделью данных, мерами и визуализациями.

## Примечание

Проект выполнен на учебных данных. Результаты демонстрируют технические навыки и подход к аналитическим задачам, но не являются показателями реального бизнеса.
