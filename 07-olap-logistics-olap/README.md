# OLAP-модель для анализа эффективности международных поставок

## 1. Описание проекта

Разработка аналитической OLAP-модели в Microsoft Excel для оценки эффективности международных логистических операций.

Проект демонстрирует построение многомерной модели данных, разработку DAX-мер, выполнение OLAP-операций и создание интерактивного BI-дашборда.

**Бизнес-задача:** предоставить инструмент для анализа логистических расходов, своевременности доставки, эффективности перевозчиков и отклонений фактических затрат от плановых.

## 2. Инструменты

- Microsoft Excel 365
- Power Pivot
- Data Model
- DAX
- PivotTables
- PivotCharts
- OLAP

## 3. Данные и модель

Для проекта использован синтетический набор данных, имитирующий международные логистические операции.

Основные характеристики:
- 15 000 записей о поставках.
- 1 факт-таблица `FactShipments`.
- 6 таблиц измерений:
  - `DimDate`
  - `DimSupplier`
  - `DimCarrier`
  - `DimGeography`
  - `DimProduct`
  - `DimTransport`

**Гранулярность фактов:** одна запись соответствует одной поставке.

Модель построена по принципу Star Schema. Связи между таблицами реализованы по ключам измерений.

## 4. Реализованные аналитические показатели

Разработаны DAX-меры для расчёта:

- Total Shipments
- Total Logistics Cost
- Average Cost per Shipment
- On-Time Delivery %
- Average Delivery Delay
- Cost Variance
- Cost Plan Adherence %

Показатели позволяют анализировать объём операций, структуру затрат, своевременность поставок и отклонения от бюджета.

## 5. OLAP-операции

В проекте реализованы основные операции многомерного анализа:

- **Slice** — анализ затрат по одному виду транспорта.
- **Dice** — одновременная фильтрация по виду транспорта и поставщику.
- **Drill-down** — детализация затрат по месяцам.
- **Roll-up** — агрегирование затрат по годам.
- **Pivot** — изменение аналитического представления данных по годам и видам транспорта.

## 6. Интерактивный Dashboard

Разработан дашборд для мониторинга ключевых логистических показателей.

Основные аналитические направления:
- динамика логистических затрат;
- сравнение затрат по перевозчикам;
- задержки доставки по регионам;
- сравнение эффективности видов транспорта;
- анализ плановых и фактических расходов.

Предусмотрены интерактивные срезы по году, поставщику, виду транспорта и региону.

## 7. Основные результаты анализа

По результатам исследования данных:

- Общее количество поставок — 15 000.
- Общие фактические логистические затраты — 28,42 млн.
- Доля своевременных доставок — 42,30%.
- Превышение плановых расходов — 1,07 млн.
- Air имеет наибольшую среднюю стоимость одной отправки — 3 302,86.
- Sea демонстрирует наибольшую своевременность доставки — 42,66%.
- Road имеет наибольшую среднюю задержку — около 2,43 дня.
- Carrier 11 показывает максимальное превышение плановых расходов — 94 191.

## 8. Практическая ценность

Разработанная модель позволяет:
- контролировать логистические расходы;
- выявлять перевозчиков с наибольшими отклонениями от бюджета;
- сравнивать виды транспорта по стоимости и своевременности;
- анализировать региональные различия;
- получать детализацию показателей с помощью интерактивной фильтрации.

## 9. Статус проекта

Проект выполнен на синтетических данных и предназначен для демонстрации практических навыков моделирования данных, DAX и BI-аналитики.

**Основной результат:** интерактивная OLAP-модель и аналитический Dashboard в Microsoft Excel.
