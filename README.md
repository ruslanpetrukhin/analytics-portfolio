# Data Analytics Portfolio

Портфолио проектов в области Data Analytics, BI и Product Analytics.

## Обо мне

Data Analyst / BI Analyst. Работаю с SQL, Python и Power BI. Развиваю навыки анализа данных, построения аналитических моделей и решения бизнес-задач на основе данных.

## Технический стек

- **SQL:** PostgreSQL, JOIN, CTE, оконные функции, агрегаты, представления.
- **Python:** pandas, NumPy, Matplotlib, Seaborn.
- **BI:** Power BI, DAX, Power Query.
- **Data Engineering:** основы DWH, моделирование данных, dbt.
- **Product Analytics:** метрики продукта, когортный анализ, A/B-тестирование.
