# Data Analytics Portfolio

Портфолио практических проектов в области **Data Analytics, BI и Product Analytics**.

Проекты охватывают основные этапы аналитической работы: получение и подготовку данных, исследовательский анализ, построение аналитических моделей, расчёт бизнес-метрик, разработку BI-отчётности и оценку результатов экспериментов.

## Обо мне

**Data Analyst / BI Analyst**

Работаю с SQL, Python и Power BI. Развиваю компетенции в анализе данных, проектировании аналитических моделей, расчёте бизнес-показателей и визуализации результатов.

Основной фокус — решение бизнес-задач на основе данных, поиск закономерностей и формирование обоснованных аналитических выводов.

## Технический стек

- **SQL:** PostgreSQL, JOIN, CTE, оконные функции, агрегатные запросы, VIEW.
- **Python:** pandas, NumPy, Jupyter Notebook, очистка данных, EDA, группировка, агрегация и визуализация.
- **BI:** Power BI, DAX, Power Query, моделирование данных, интерактивные дашборды.
- **Statistics & Product Analytics:** A/B-тестирование, z-тест для двух долей, p-value, доверительные интервалы, продуктовые метрики, когортный анализ.
- **Data Warehousing:** DWH, Star Schema, факты и измерения, SCD Type 2.
- **Data Engineering:** основы ELT, проектирование dbt-моделей, tests, macros и snapshots.

### 07. OLAP Logistics

**OLAP-модель для анализа эффективности международных поставок**

Многомерная модель данных и интерактивный аналитический дашборд в Excel 365.

**Что реализовано:**
- Построение модели данных по принципу Star Schema.
- Создание модели в Power Pivot и настройка связей между таблицами.
- Разработка мер DAX для анализа логистических затрат, сроков доставки и отклонений от бюджета.
- Применение OLAP-операций: Slice, Dice, Drill-down, Roll-up и Pivot.
- Сравнение эффективности перевозчиков и видов транспорта.
- Создание интерактивного дашборда с диаграммами, сводными таблицами и срезами.

**Результаты анализа:** 15 000 поставок, фактические логистические затраты — 28,42 млн, доля своевременных доставок — 42,30%.

[Перейти к проекту](./07-olap-logistics-olap/README.md)
