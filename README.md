# Data Analytics Portfolio

Портфолио проектов в области Data Analytics, BI и Product Analytics.

Проекты демонстрируют работу с данными на разных этапах: от извлечения и очистки до анализа, моделирования, визуализации и оценки бизнес-эффекта.

## Обо мне

Data Analyst / BI Analyst.

Работаю с SQL, Python и Power BI. Развиваю компетенции в аналитическом моделировании, продуктовой аналитике и статистическом анализе.

Основной фокус — превращение данных в понятные бизнес-метрики и аналитические решения.

## Технический стек

- **SQL:** PostgreSQL, JOIN, CTE, оконные функции, агрегаты, представления, анализ выполнения запросов.
- **Python:** pandas, NumPy, Matplotlib, Seaborn, очистка данных, EDA.
- **BI:** Power BI, DAX, Power Query, моделирование данных и визуализация.
- **Statistics & Product Analytics:** A/B-тестирование, статистическая значимость, продуктовые метрики, когортный анализ.
- **Data Engineering:** основы DWH, Star Schema, SCD Type 2, ELT, проектирование dbt-моделей.

## Проекты

### 01. SQL и PostgreSQL

Анализ данных интернет-магазина: заказы, выручка, товары и клиенты.

Что реализовано:
- SQL-запросы с JOIN, CTE и оконными функциями.
- Анализ выручки и динамики продаж.
- Рейтинг товаров и клиентов.
- Анализ повторных покупок.
- Представления для повторного использования аналитической логики.

[Перейти к проекту](./01-sql-postgresql/)

### 02. Python — Data Analysis

Исследовательский анализ данных интернет-магазина.

Что реализовано:
- Очистка и проверка качества данных.
- Обработка пропусков, дубликатов и некорректных значений.
- EDA и анализ динамики продаж.
- ABC/XYZ-анализ товарного ассортимента.
- Визуализация результатов.

[Перейти к проекту](./02-python-data-analysis/)

### 03. Python + PostgreSQL

Интеграция Python с PostgreSQL для извлечения и анализа данных.

Что реализовано:
- Подключение к PostgreSQL через SQLAlchemy.
- Извлечение данных с помощью SQL.
- Обработка и анализ данных через pandas.
- Работа с результатами SQL-запросов в Python.

[Перейти к проекту](./03-python-postgresql/)

### 04. Power BI — PostgreSQL Data Analysis

BI-отчёт на основе данных PostgreSQL.

Что реализовано:
- Подключение Power BI к PostgreSQL.
- Построение модели данных и настройка связей.
- Создание календарной таблицы.
- Разработка DAX-мер.
- Анализ выручки, среднего чека и количества заказов.
- MoM-динамика и рейтинг товаров.
- Исключение отменённых заказов из расчёта выручки.

[Перейти к проекту](./04-power-bi/)

### 05. A/B Testing

Excel-калькулятор для оценки результатов A/B-экспериментов.

Что реализовано:
- Сравнение конверсии контрольной и тестовой групп.
- Расчёт статистической значимости.
- Оценка изменения прибыли и прибыли на пользователя.
- Анализ среднего чека, возвратов и отмен.
- Использование защитных метрик при принятии решения.

[Перейти к проекту](./05-ab-testing/)

### 06. Data Warehouse & dbt Architecture

Проектирование аналитического хранилища данных для e-commerce.

Что проработано:
- Архитектура DWH и ELT-процесса.
- Модель данных Star Schema.
- Разделение на факты и измерения.
- Историчность клиентских атрибутов через SCD Type 2.
- Проектирование dbt-моделей, macros, tests и snapshots.
- Подходы к incremental-моделям.

**Статус:** архитектура и реализация описаны в документации; DWH и dbt-пайплайн пока не развёрнуты.

[Перейти к проекту](./06-dwh-dbt/)
